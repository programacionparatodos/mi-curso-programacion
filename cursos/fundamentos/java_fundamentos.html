Módulo 1: Fundamentos de Java y Entorno Virtual (JVM)

Estructura base de una clase en Java y el método principal (main). Anatomía de la ejecución mediante la JVM. Declaración de variables, uso de constantes, ámbito de datos y tipado fuertemente estático.

Módulo 2: Flujos de Consola y Operadores

Entrada de datos interactiva mediante la clase nativa Scanner. Salida estructurada de información por terminal con System.out.print y formateo de datos. Operadores relacionales, aritméticos y lógicos.

Módulo 3: Estructuras Condicionales y Bucles

Flujos de control secuenciales y bifurcaciones condicionales avanzadas (if / else / switch). Implementación segura de estructuras repetitivas cíclicas iterativas (while / do-while / for).

Módulo 4: Manipulación Segura de Cadenas de Caracteres

Uso avanzado del objeto nativo String en el pool de memoria. Medición con .length(), extracción con .substring() y comparación segura de contenidos mediante el método .equals() evitando errores de referencia física.

Módulo 5: Estructuras de Datos Estáticas y Colecciones Dinámicas

Declaración, inicialización y reserva de memoria para arreglos estáticos unidimensionales (vectores) y bidimensionales (matrices). Introducción al framework de colecciones mediante estructuras dinámicas lineales con la clase ArrayList.

Módulo 6: Modularidad y Estructura de Métodos

Diseño, declaración e invocación de bloques de código modulares mediante métodos estáticos (static). Transferencia segura de información: paso de parámetros por valor, control de ámbito de variables y retorno estructurado de tipos de datos.
