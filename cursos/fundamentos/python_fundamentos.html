Módulo 1: Fundamentos de Python e I/O de Datos

Introducción al entorno interpretado de Python. Declaración de variables, tipado dinámico y manejo de operadores. Formateo avanzado de salida de información mediante cadenas literales f-strings.

Módulo 2: Estructuras de Control de Flujo

Implementación de bloques condicionales anidados (if-elif-else). Control y automatización de bucles e iteraciones repetitivas (while / for-in) y control de ciclos con break y continue.

Módulo 3: Estructuras de Datos Secuenciales

Gestión avanzada de listas mutables (indexación por coordenadas, segmentación dinámica con slicing y manipulación con el método .split). Creación y consulta de colecciones estructuradas mediante diccionarios clave-valor y colecciones bidimensionales.

Módulo 4: Modularidad y Robustez de Código

Estructuración de funciones modulares reutilizables mediante la instrucción estándar def, transferencia de parámetros y retorno controlado de valores. Prevención y mitigación de interrupciones de sistema controlando errores con bloques try-except.

Módulo 5: Persistencia Local en Estructuras JSON

Lectura y escritura permanente de datos en archivos locales del disco duro mediante el módulo nativo json. Transformación y serialización de diccionarios complejos para resguardar la información del sistema.
